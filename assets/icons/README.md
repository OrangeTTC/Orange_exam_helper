# Orange 考研助手图标

项目署名：Orange。

生成方式：内置 imagegen 工具；生成透明 PNG，再导出包含 16、24、32、48、64、128、256 像素尺寸的 Windows ICO。PNG 为原始生成文件，保留透明通道。

文件：orange-study.png、orange-study.ico。

本次创建图标资源，尚未替换程序的窗口图标或可执行文件图标。

## 最终生成提示

Use case: logo-brand.
Asset type: a polished square desktop application icon for an orange-themed study assistant.
Primary request: a single ripe mandarin orange with one graceful green leaf, designed as a recognizable app icon.
Style: refined stylized 3D illustration, softly rounded geometry, warm orange peel with very subtle texture, restrained highlights, elegant and friendly, clean bold silhouette.
Composition: centered single orange, compact circular body, leaf curves above it; subject fills about 82 percent of a square canvas with comfortable transparent margins. Attractive at 256px and clearly legible at 32px. A tiny darker stem connects the leaf to the fruit.
Backdrop: genuinely transparent background with preserved alpha, no floor, no cast shadow outside the fruit.
Constraints: one icon only; no text, no letters, no watermark, no border, no rounded-square tile, no mockup, no extra objects, no human face. Strong visual contrast, visually balanced leaf and fruit.
