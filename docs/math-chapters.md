# 数学（一）教材章节目录

依据 Orange 于 2026-10-10 提供的三张目录照片整理。教材书名和版本尚未提供，不推断这些信息；页码仅指照片中的教材页码。手写旁注不作为章节名称。

章节保存为完整的 `板块 · 讲次 名称` 字符串，顺序遵循照片，包含第 0 讲和附录。目录共 37 项：高等数学 24 项（18 讲、6 个附录），线性代数 7 讲，概率论与数理统计 6 讲。

录入时优先从目录选章，未知时用“待标注”。细分知识点、关联章节写入笔记；跨章题按主要解题内容选一个章节。其他学科的章节保持自定义。

“数学章节目录”显示三组章节及本地数学题目数量，零题章节仍可访问。双击具体章或点击“查看题目”会进入数学（一）、按章节筛选并清除其他筛选条件。组标题仅用于目录分组。录入窗口及章节筛选共用同一份目录，旧标签继续出现在“其他 / 自定义章节”。
